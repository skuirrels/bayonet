- **Restored on open:** opening a solution that hasn't been restored no longer leaves it full of errors. Roslyn restores the projects itself, and Bayonet now tells it when the restore has written `obj/project.assets.json`, so the projects reload and the errors go away.
- **Rider's context menus:** right-clicking the solution in Solution Explorer offers Add, Manage NuGet Packages, Reload All Projects, Save as .slnx, Build Solution, Run and Cover Unit Tests, Advanced Build Actions, Show Local History, Inspect Code, Reformat and Cleanup, Edit, Copy Path, Open In, Diagrams and Manage .NET SDK. A project's menu starts with Add (new files, project references and NuGet packages), Edit, Entity Framework Core, user secrets, Build and Rebuild Selected Projects, its unit tests, Publish and Run in Container.
