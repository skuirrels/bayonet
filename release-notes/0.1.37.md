The first release of Bayonet, an open-source .NET IDE ported from OpenIDEA.

- **Solutions:** opens `.sln`, `.slnx` and `.slnf` files in Solution Explorer, with solution folders, dependencies, `Directory.Build.props` and central package management.
- **Code intelligence:** Roslyn completion, navigation, find usages, inlay hints, analyser diagnostics and refactorings for C#, plus F# through FsAutoComplete.
- **Build, run and debug:** build, rebuild and publish, run configurations, Hot Reload, and netcoredbg debugging with attach to process and Parallel Stacks.
- **NuGet and tests:** a NuGet window for search, install, update and private feeds, and a Unit Tests window for xUnit, NUnit and MSTest with coverage.
- **Updates:** Bayonet checks for new versions when it starts and from **Help ▸ Check for Updates**.

macOS builds are not notarised yet: the first time, right-click Bayonet in Applications and choose **Open**.
