- **Open a solution file:** **File ▸ Open Solution…** opens a `.sln`, `.slnx` or `.slnf`, and so does dropping one on the Welcome screen, passing it on the command line or using Finder's Open With. Bayonet opens its folder and uses that solution in Solution Explorer, for builds, runs, tests and NuGet, and remembers it next time. Opening another solution in the same folder switches to it.

macOS builds are not notarised yet: the first time, right-click Bayonet in Applications and choose **Open**.
