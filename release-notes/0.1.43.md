- **.NET 11:** Bayonet works with the .NET 11 SDK. The New Project dialog now offers every target framework you have templates for, newest first, so with SDK 11 you can still create a `net10.0` (LTS) project. Before, it offered only the newest one.
- **Debugging right after a project opens:** starting the debugger, or anything else that needs the language server, no longer fails when the server is restarting at that moment. Java showed this as "jdtls is not ready (Busy)", because jdtls restarts once Maven has loaded the project. The request now waits for the restarted server.
- **Faster start-up:** the File Structure popup, the Run console in Services and the external Git log now load when first used instead of at start-up.

macOS builds are not notarised yet: the first time, right-click Bayonet in Applications and choose **Open**.
