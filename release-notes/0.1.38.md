- **CPU traces down to the line:** the Diagnostics window's CPU Trace now records with Bayonet's own helper. The editor shows how long each line of your code took, and the trace lists garbage collections, total GC pause time and the longest pause. Traces from the helper are kept as `.nettrace` files you can reopen.
- **Rider colours for C#:** the Islands Dark and Light editor schemes now use Rider's colours, and fields, constants, events, delegates, record structs, extension methods, string escapes and XML doc comment tags each get their own colour. `.icls` import and export carry the ReSharper attributes.
- **Decompiled sources:** Go to Definition on a type from a referenced assembly opens its decompiled source.
- **From OpenIDEA:** full values on click in the debugger's Variables and inline values, clickable file locations in the build console, terminals that keep their working directory across restarts, and many smaller fixes.

macOS builds are not notarised yet: the first time, right-click Bayonet in Applications and choose **Open**.
