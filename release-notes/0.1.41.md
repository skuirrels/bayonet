- **New icon:** Bayonet has a new app icon, a black "BN" square on a rounded violet tile.
- **Dotfiles hidden by default:** the project tree no longer lists names starting with a dot, such as `.env` and `.gitignore`. Turn on **Show Dotfiles** in the Project view's options menu, or from Find Action, to see them. Search, indexing and Git changes still include them.
- **Shorter context menu:** Cut, Copy, Copy Path/Reference, Paste and Delete are now in one **Edit** submenu, so a file's context menu fits without a scrollbar. Menus opened low in the window move up to fit instead of scrolling.

macOS builds are not notarised yet: the first time, right-click Bayonet in Applications and choose **Open**.
