- **Python interpreter status:** in a project whose only Python is loose scripts, such as a .NET repository's tooling scripts, the interpreter item and its **No interpreter** warning now show only while a Python file is the active tab. Projects with Python project files (`pyproject.toml`, `requirements.txt` and so on) or a configured interpreter still show it everywhere.

macOS builds are not notarised yet: the first time, right-click Bayonet in Applications and choose **Open**.
