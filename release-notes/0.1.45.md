- **XAML completion:** in WPF, Avalonia, MAUI and WinUI files, completion now offers the elements, attributes, attached properties and enum values of the UI framework and of your own types, read from the assemblies the project builds against.
- **Show IL:** a new **Show IL** action shows the IL of the type or member at the caret.
- **Rename a type and its file:** renaming a C# type also renames the file named after it.
- **VSTest projects:** test projects that only use VSTest can now be discovered, run, debugged and run with coverage.
- **What keeps objects alive:** in the Memory tab, **Find What Retains Objects** adds a Retained column to a gcdump and shows the paths from the GC roots for the selected type.
- **Debugger:** LINQ expressions with lambdas, such as `list.Where(x => x > 2).Count()`, now evaluate under netcoredbg. Dictionaries and HashSets show as key/value and item lists, and hovering a variable shows its value.
- **Attach over SSH:** Attach to Process can pick **Where the process runs** and attach to .NET processes on a Linux host over SSH.
- **Security:** russh is updated to 0.65 for RUSTSEC-2026-0495.

macOS builds are not notarised yet: the first time, right-click Bayonet in Applications and choose **Open**.
